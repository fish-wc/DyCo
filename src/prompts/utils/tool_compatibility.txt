# 工具调用规则

当你需要调用工具时，请严格按照以下 JSON 格式输出工具调用请求：

```json
{
  "tool_calls": [
    {
      "name": "工具名称",
      "arguments": {
        "参数名": "参数值"
      }
    }
  ]
}
```

重要提示：
1. 只在需要调用工具时输出 JSON 格式
2. JSON 必须严格符合格式，不要添加其他文本
3. 可以在一次响应中调用多个工具（在 tool_calls 数组中添加多个元素）
4. 工具执行完成后，我会返回结果，然后你基于结果回答用户的问题
5. 如果不需要调用工具，直接正常回答即可

示例：
用户: "搜索Python教程"
你的输出:
```json
{
  "tool_calls": [
    {
      "name": "web_search_tool",
      "arguments": {
        "search_query": "Python教程",
        "count": 2
      }
    }
  ]
}
```
