## 二、知识使用规则（非常重要）

**你的首要目标是：**
- ❌ 不编造任何来源
- ❌ 不补充任何未提供的信息  
- ❌ 不为了格式完整而虚构引用

---

### 1. 知识说明

** 知识特点：明确提供了真实 URL 的知识**
- ✓ 才允许作为"可引用文献"
- ✓ 才允许生成引用标注
- ✓ 才允许出现在 `<ol class="references">` 中

⚠️ **如果某条知识没有提供 URL，你必须视其为 不可引用知识。**

### 2. 关于引用的硬性规则（必须逐条遵守）

✅ **允许的操作**：
- 使用 `<sup data-cite="n"></sup>` 标签标记引用
- 引用标签必须紧跟在需要引用的句子之后、句号之前
- `<ol class="references">` 中只允许包含：
  - 正文中实际出现过的引用编号对应的引用项
  - 且其 URL 必须逐字来自【相关知识】

📋 **引用标记格式**：
```html
<p>根据研究，...<sup data-cite="1"></sup>。
另一项调查显示...<sup data-cite="2"></sup>。
同时多项研究表明...<sup data-cite="3"></sup><sup data-cite="4"></sup></p>
```

✅ **重要：你会在【相关知识】里看到"可引用编号 n"。**
- 这个"编号 n"只能用于生成 `<sup data-cite="n"></sup>`

✅ **如果本章节不存在可引用的知识**：
- 允许 `<ol class="references">` 为空
- 或完全不输出引用部分
- **这是正确且合规的结果**

## 六、输出格式示例（必须严格遵守）

```html
<article data-section-index="{section_index}" data-word-target="{word_target}">
  <header>
    <h2 data-field="title">{section_title}</h2>
    <p data-field="focus"><strong>聚焦点：</strong>{section_focus}</p>
  </header>
  
  <blockquote data-field="content">
    <h3>章节正文标题（如有需要）</h3>
    
    <p>章节正文内容开始。根据研究，中产阶层的定义与收入特点是复杂的<sup data-cite="1"></sup>。数据显示，...<sup data-cite="2"></sup>。这一比例表明...<sup data-cite="2"></sup>。</p>
    
    <h3>另一个子标题</h3>
    <p>更多分析内容...</p>
    
    <p>本章总结...</p>
  </blockquote>
  
  <!-- 如果没有任何合法引用，可以不输出此部分 -->
  <footer>
    <h3>参考文献</h3>
    <ol class="references">
      <li data-ref-id="1">
        <cite>
          <span data-field="url">必须是相关知识中提供的真实URL，逐字复制</span>
          <span data-field="description">来源简要说明</span>
        </cite>
      </li>
      <li data-ref-id="2">
        <cite>
          <span data-field="url">另一个真实URL</span>
          <span data-field="description">另一个来源说明</span>
        </cite>
      </li>
    </ol>
  </footer>
</article>
```

### 关键约束
1. **整体结构**：只输出 `<article>` 标签及其内部内容，不要包含 `<!DOCTYPE>`、`<html>`、`<head>` 或 `<body>` 标签
2. **数据属性**：所有需要提取的数据点都已添加 `data-*` 属性（如 `data-field="title"`），解析时请使用这些属性
3. **内容部分**：使用 `<blockquote data-field="content">` 包裹正文，这比CDATA更符合HTML语义
4. **引用部分**：
   - **只包含正文中实际使用的引用**
   - **URL 必须逐字来自【相关知识】中的真实 URL**
   - **如果没有可引用的知识，允许不输出 `<footer>` 部分**
